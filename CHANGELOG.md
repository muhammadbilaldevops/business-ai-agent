# Changelog

## 0.2.0

- Added Next.js workspace with separate browser-demo and local API adapters.
- Added PDF/Office extraction, deterministic chunking, BM25, optional local Qdrant/BGE retrieval and reranking.
- Added durable LangGraph workflows and approval interrupts with atomic task/report execution.
- Added bounded DuckDB queries, persistent conversations, local preferences, audit records, and SSE.
- Added optional Ollama and local voice adapters with explicit unavailable states.
- Added backend, security, contract, evaluation, Playwright, and CI workflows.
- Added beginner setup, sample data, architecture decisions, specification coverage, and validation documentation.

The original foundation remains in Git history. This release does not claim all advanced specification items are complete or verified.
