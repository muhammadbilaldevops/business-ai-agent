# Evaluation

The committed `evaluation-results.json` is generated by `python scripts/run_evaluation.py`. It contains each input, observed route/source IDs, pass/fail, environment metadata, and local latency statistics.

The golden set tests 12 deterministic routing/source scenarios. It caught a real lexical mismatch between “refund” and “refunds”; plural normalization was added to the retriever rather than weakening the expected result.

These measurements are **not** LLM answer correctness, faithfulness, calibrated confidence, citation entailment, multilingual coverage, speech recognition accuracy, or end-to-end voice latency. Latencies reflect a tiny corpus and are not representative of a large business workspace. No production performance claim follows from this test.

Before enabling models in a business deployment, expand the corpus to real representative documents with permission, include unanswerable/adversarial questions, label exact supporting passages, record model/version/hardware, and measure source recall, response faithfulness, task completion, and tail latency separately. Keep private datasets out of Git.
